# Cian Spillane

My personal website: essays, notes on books, and projects. Plain HTML, CSS and JavaScript, no build step.

- **Books:** edit `js/books.js` (it feeds the bookshelf and the idea map)
- **Essays:** copy `essays/_template.html`, then add it to `essays.html`
- **Projects:** edit `projects.html`

Open `index.html` in a browser to preview.
